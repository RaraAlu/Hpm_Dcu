# 单拍 PDO 相位窗口实板验证

沿用 [SM2 接收槽直写](单拍PDO接收槽直写实测.md)。本轮诊断固件和独立 IgH 探针均指定发布提前量 399 µs，构建预算仍为 600 µs，固件发布截止为 Sync0 后 601 µs。1 kHz 主站以 +255 µs 配置 Sync0、+870 µs 请求 SM3、+975 µs 开始收集。按标称相位，TxPDO 最晚发布时刻为拍起点 +856 µs。生产固件默认值未改。

两轮均使用 CPU6、FIFO 80 和锁内存，运行前未发现无关用户线程或设备 IRQ 指向 CPU6，临时调整的亲和掩码在结束时恢复。未接 CAN、未下发 Profile、未改 PDO 布局、未切生产 DriverModule。两端只读 Profile 值一致。

| 验收 | 结果 | 成功帧读回时刻（相对第 N 拍起点） |
| --- | --- | --- |
| 短跑 32 拍 | 32/32，同序号、双向 WKC 1、从站保持 OP | +981.387 至 +982.541 µs，最小余量 17.459 µs |
| 60 秒目标 | 前 508 拍通过，第 509 拍停止 | 成功帧 +981.380 至 +984.389 µs；未跑满 60 秒 |

失败拍发送序号 5400，在 +982.198 µs 读回 5399，双向 WKC 仍为 1，读回时仍在 OP。HPM 在本轮第 516 个工作周期的 Sync0 判定 `RX_MISSING`，不是 `TX_LATE`。相邻两帧的 HPM 本地时间以各自 Sync0 为基准：

| 命令 | SM2 事件 | ESC 开始读 | ESC 读完 | RxPDO 槽提交 |
| --- | ---: | ---: | ---: | ---: |
| 5399 | −135 µs | −126 µs | −13 µs | −4 µs |
| 5400 | −132 µs | −123 µs | −10 µs | +8 µs |

两拍 ESC 读取均为 113 µs。失败时读完已有 10 µs，但 Sync0 检查时接收槽仍在写入交接流程，最终提交完成晚了 8 µs。HPM 随后报告同步错误并退出 OP。不能把这次失败归因于主站读回超时或 TxPDO 发布超时，也不能把读完后的全部时间归为复制开销。

离线 51 项回归通过，包含原相位和本轮相位的探针模型。诊断 ELF 反汇编确认传入发布提前量 399，烧录前后 SII 保留区一致，启动编号日志追加 87、88。测试结束后主站 Idle，HPM 退 PREOP 后由 J-Link 暂停。主站 CSV、IgH 日志、HPM RAM 轨迹和镜像在 `artifacts/target/pdo-window-255-870-20261119/`。
