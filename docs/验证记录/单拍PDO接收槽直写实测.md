# 单拍 PDO 接收槽直写实测

原 OP 路径先把 SM2 从 ESC 读入 SSC 临时缓冲，再拷贝到 MCU 的 RxPDO 槽。现在 SSC 的输出映射先向周期模块借一个空槽，用对齐的 32 位读取直接填槽，读完整块后才原子提交。写入中的槽对 Sync0 不可见；无可用槽、地址或长度不满足要求时沿用 SSC 原路径，不跳过 SM2 读取与确认。不改变 SSC 的 AL 状态机和同步检查。

离线逐字节核对 544、736、784 字节，检查尾部不越界、错误长度被拒绝和停机后不再读取，并模拟 Sync0 在写入首字后打断：半帧不可见，完整帧只能在后续 Sync0 被取走。EtherCAT、流水线、头文件归属和工程结构共 66 项测试通过；Release、相位诊断版、独立 EtherCAT 数据镜像均构建通过。

CPU6、FIFO 80、锁内存，用同一个独立 IgH 探针短跑 1 kHz。以 [前轮四字 TxPDO 镜像](单拍PDO发布分段实板对照.md) 作对照，保留该 TxPDO 实现。两版各 8 条 HPM 接收轨迹；本轮逐条确认走直写。下表均为 HPM 本地计时。

| SM2 接收段 | SSC 中转 | 直接写槽 |
| --- | ---: | ---: |
| PDI 观察到 SM2 至开始读 ESC，中位数 | 6 µs | 9 µs |
| 32 位 ESC 读，中位数（范围） | 119 µs（118–119） | 119 µs（118–119） |
| ESC 读完至槽提交，中位数（范围） | 17 µs（17–20） | 10 µs（8–11） |
| PDI 观察到 SM2 至槽提交，中位数（范围） | 142 µs（141–145） | 138 µs（136–140） |

去掉中转后，读完到提交少了 7 µs；读前预留槽等开销增加了约 3 µs，整段净省约 4 µs。相对主站帧起点，槽就绪约为 +232 至 +237 µs（通过 DC 时钟对齐估算）。这个跨设备比较还包含主站发帧和 PDI 到达时间的变动，不能把就绪点的全部提前量算给直写。

**单拍未通过。** 首条严格验收发出 4956；主站于 +994.604 µs 读回 4955，双向 WKC 都是 1、从站仍在 OP。4956 约在 +232.6 µs 就绪，错过当拍约 +120 µs 的 Sync0，在约 +1123.6 µs 才被锁存。探针当即停止，不把后续发布算成 N+1 验收通过。主要剩余耗时是 ESC 本体 32 位读取，不是槽复制。

未改 Sync0/SM3 相位、600 µs 构建预算、发布截止、Profile 或 PDO 布局；未接 CAN，未切换生产 DriverModule。SII 前后回读一致，启动编号日志顺序追加 85、86。探针退出后主站回到 Idle，HPM 退 PREOP 后由 J-Link 暂停，保留直写诊断镜像。原始证据见 `artifacts/target/pdo-rx-direct-20261119/`。
