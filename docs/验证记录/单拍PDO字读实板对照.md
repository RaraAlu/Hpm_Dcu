# 单拍 PDO 字读实板对照

仅将 SSC 通过 PDI 读取的整块、对齐 SM2 数据改为 32 位 ESC 读取。非 SM2、非整块或不对齐仍走原路径；不写死 ESC 偏移，也不改变 SyncManager、Profile 或 PDO 布局。离线逐字节对照 544、736、784 字节及小块数据，覆盖四种目标地址对齐和不越界检查；32 项 EtherCAT 相关测试通过。诊断镜像反汇编确认 ESC 循环使用 `lw`。

RK3588 CPU6 使用同一个独立 IgH 探针，1 kHz、FIFO 80、锁内存。Sync0/SM3 读请求/收集标称相位仍为 +120/+885/+975 µs，600 µs 构建预算和发布截止策略均不变。未接 CAN，未切生产 DriverModule，Profile 只读核对前后一致。

| 指标 | [逐字节读取基线](单拍PDO接收分段实测.md) | 32 位读取 |
| --- | ---: | ---: |
| ESC 读取，HPM 本地计时，各 8 条 | 260 µs | 118–119 µs |
| RxPDO 槽提交完成，相对主站拍起点 | 约 +387–395 µs | 约 +242–252 µs |
| 首条严格验收结果 | 4841 收到 4840 | 4848 收到 4847 |

读段节省 141–142 µs（约 54%）。首拍 4848 的槽约在 +247 µs 才就绪，错过约 +121 µs 的首个 Sync0，只能在约 +1121 µs 锁存，约 +1439 µs 发布。主站在 +997.532 µs 收到的是旧反馈 4847，双向 WKC 均为 1，仍处于 OP。探针原计划验收 32 拍，但第一拍即失败并停止；8 条 MCU 诊断轨迹不是 8 条严格通过样本。跨设备相位由 ESC DC 时钟估算，不是物理边沿测量。

若保持当前接收路径，要把 Sync0 移到 RxPDO 槽就绪之后，同时保证 TxPDO 在本拍 SM3 读之前发布。可先仅在独立探针试 +280 µs（距这次最晚槽提交约 28 µs），不改 SM3 时间、不放宽任何保护；这只是复测起点，本轮未改相位，也未证明一拍通过。

烧录前后 SII 回读一致；启动日志正常追加 79，并轮换旧扇区记录 80，未重新初始化。结束后从站已退回 PREOP，主站 Idle，HPM 暂停用于回读。原始数据见 `artifacts/target/pdo-sm2-word-20261119/`。
