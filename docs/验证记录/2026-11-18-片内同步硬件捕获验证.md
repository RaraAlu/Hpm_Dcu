# 片内同步硬件捕获验证

测量路径是 ESC Sync0 → TRGM0 → GPTMR0 通道 2 硬件上升沿捕获。烧录前回读确认该通道未启用、对应 TRGM 输出未配置。沿用 GPTMR0 的 100 MHz 现有时钟，计数分辨率 10 ns。没有修改时钟、全局控制或中断配置；烧录前后回读确认同实例的 EtherCAT 定时器通道 0 配置保持一致。

| 指标 | 实测结果 |
| --- | --- |
| 空载 PDO | CPU 4、锁内存、FIFO 80；1 ms 周期完成 60000 拍，所有 WKC 为 2。 |
| 硬件捕获覆盖 | 60014 次 Sync0 观测对应 60014 个捕获标记，无缺捕获或合并，含短暂 OP 预热及收尾，共 60013 个周期、约 60.015 秒。32 位计数器回绕一次，累计计数校核通过。 |
| Sync0 周期 | 999.990–1000.160 µs，平均 1000.034 µs。 |
| 逐周期间隔偏差 | 相对 1 ms 为 -0.010 至 +0.160 µs，超出 ±1 µs 为 0 次。 |

这里用硬件捕获寄存器的相邻时间戳计算，不把读取寄存器或进入 ISR 的时刻当作边沿。通过的是这次空载运行内、相对 MCU 本地计数时钟的片内 Sync0 周期验收，不代表外部引脚波形、相对独立时基的绝对频率或长期相位精度。
