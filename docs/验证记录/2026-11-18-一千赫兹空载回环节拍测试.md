# 一千赫兹空载回环节拍测试

RK3588 使用 CPU 4、SCHED_FIFO 80、`mlockall`。IgH 在 1 ms 主站周期和 1 ms Sync0 下连续完成 60000 个空载零使能 PDO，计划和观测均为 60 秒。WKC 异常和应答跳号为 0；最后 3 个在途应答不在统计窗口内。正常停止进入 PREOP，AL 状态码为 0。

| 指标 | 实测 |
| --- | --- |
| 主站发送调用间隔 | 991.962–1010.921 µs，均值 1000.000 µs；相对 1 ms 的绝对偏差 P99.9 为 7.129 µs，最大 10.921 µs。 |
| 发送余量 | IgH 发送调用返回到主站下一目标拍至少 973.759 µs。MCU 完成对应 RxPDO 槽复制到 Sync0 ISR 的有效余量 459–541 µs，中位数 531 µs。两端未校准成同一时基，未直接测物理线上发帧到 Sync0 边沿的时间差。 |
| MCU Sync0 节拍 | 有效 RxPDO 连续锁存的 Sync0 ISR 间隔 992–1008 µs，均值 1000.040 µs；相对 1 ms 的绝对偏差 P99.9 为 4 µs，最大 8 µs。来自 MCU 的 1 µs 时基，ESC 引脚物理边沿的 ±1 µs 未在本轮验证。 |
| PDO 应答 | 发送调用到主站按序号观察到应答为 2.988–3.011 ms，中位数约 3.000 ms，应答更新的间隔相对 1 ms 的绝对偏差 P99.9 为 6.546 µs、最大 10.337 µs。 |

主站的 CSV 只在循环退出后落盘。MCU 在任务端按实际锁存的快照累计直方图，采集覆盖整个 OP（含短暂预热及收尾），而主站的 CSV 只取 60000 拍。结束后才通过 J-Link 暂停并读取 MCU。耗时和直方图是软件观测，不代替外部参考时钟、物理 Sync0 或网口发帧时间戳。

CAN 未接业务节点；Profile ID/版本为 1/1，没有重新下发或提交；600 µs 准备预算和 250 µs 发布提前量不变。SII 回读一致，启动日志正常换扇区、编号递增到 67。结束后 IgH 为 Idle，MCU 保留测量版并暂停。离线 346 项（341 通过、5 跳过）。
