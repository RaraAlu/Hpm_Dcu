# 单拍 PDO 接收分段实测

沿用 [首次实板验证](单拍PDO回环首次实板验证.md) 的相位与同一个 CPU6 独立 IgH 探针，1 kHz、FIFO 80、锁内存。仅在诊断镜像增加时间戳：PDI 入口确认 SM2 事件、SSC 的原 ESC 读取调用前后、RxPDO 槽提交。没有更改原 SSC 数据搬运方法、Profile、PDO 布局或截止保护。未接 CAN，未切换生产 DriverModule。

第一条严格验收命令 4841 即失败：在 +994.369 µs 收到的是 4840，双向 WKC 均为 1、AL 为 OP。该命令的主站/HPM 配对如下：

| 事件 | 相对该拍主站起点 (µs) | HPM 本地相邻耗时 (µs) |
| --- | ---: | ---: |
| 主站 SM2 发送调用 | +3.284 | 不适用 |
| HPM PDI 入口确认 SM2 | 约 +103 | 不适用 |
| ESC 读取开始 | 约 +110 | 7 |
| ESC 读取完成 | 约 +370 | 260 |
| RxPDO 槽提交开始 | 约 +374 | 4 |
| RxPDO 槽提交完成 | 约 +387 | 13 |
| 主站发送 SM3 读、读回 4840 | +894.327、+994.369 | 不适用 |
| HPM 锁存 4841、发布 4841 | 约 +1120、+1468 | 发布距实际 Sync0 +348 |

同一个 OP 窗口的 8 条 HPM 轨迹均记录 ESC 读耗时 260 µs，槽实际提交耗时为 13–15 µs。对 4841，从主站发帧调用到 HPM 槽提交约 384 µs，ESC 读取占约 68%，是最大项；主站调用到 PDI 观察到 SM2 约 100 µs，包含发帧、线上传输和中断响应，未拆开。主站和 HPM 跨设备时间使用 ESC DC 时钟估算；同一 HPM 内的分段差值无需跨设备换算。

诊断 ELF 的反汇编确认 `HW_EscRead` 对该 PDO 走通用 `memcpy`，实际是逐字节 `lb/sb`，并非 32 位 ESC 窗口批读。优先验证兼容该 ESC 的对齐字读；读段变短后仍要重新核对 SM2、Sync0 与 SM3 的余量，不能据此宣称必然达到一拍。本轮第一拍失败后即停止，不补发通过。EEPROM/SII 回读一致，启动日志只新增 77 和 78；主站释放，HPM 退回 PREOP 后暂停用于证据回读。

原始 CSV、诊断 RAM、解析摘要和主站日志见 `artifacts/target/pdo-rx-stages-20261119/`。诊断镜像构建、保护校验和 31 项离线 EtherCAT 相关测试通过。
