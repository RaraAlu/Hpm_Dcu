# CAN2 四电机 500 Hz 八小时通宵实测

**结果：通过四轴 N+1 通信验收。** 2026-11-24 北京时间 02:10:07 至 10:10:15（含启动和收尾），RK3588 的生产 `DriverModule` 连续向同一条 CAN2 上的四台 7216（ID 1、2、3、4）发送全零 MIT 命令。14,400,000 拍全部在下一帧读到四轴对应命令的新反馈，漏拍 0；每轴独立 TX 完成计数也都增加 14,400,000。这是一次完整运行，不是多轮相加。

## 测试条件

- HPM 使用五轴台架镜像，Profile 1 / rev 10，SM2 / SM3 分别为 216 / 256 B；命令周期 2,000 µs。只有 CAN2 四轴参与命令窗口，CAN3 ID 2 作未发送对照。[当次镜像及 SHA-256](../../artifacts/target/20261123T180315.473979Z/image-check.json)
- [11 月 23 日首次通宵尝试](2026-11-23-CAN2四轴通宵回环首次运行.md)约 21 秒即因旧回显停止，未通过。改用 CAN2 硬件 TX 帧尾中断续发后，[单拍实测](../../artifacts/target/CAN2中断续发50us-PaNFKs56/结果.md)三段帧尾到下一帧提交均满足至少 50 µs；随后[六十秒测试](../../artifacts/target/CAN2中断续发50us-60s-tDKLGyIM/60s.log)通过 30,000/30,000 拍。两轮均不计入本次八小时。

## 逐拍验收

判据：第 N 帧发命令，第 N+1 帧须同时满足命令序号匹配、四个目标轴反馈均为本拍新值；仅有总线收发或上一拍的有效位不算通过。独立读回各轴 TX 完成计数，与生产线程的匹配结果交叉核对。

| 指标 | 八小时窗口结果 |
| --- | --- |
| 发出命令 / N+1 四轴全部匹配 / 漏拍 | 14,400,000 / 14,400,000 / 0 |
| CAN2 ID 1、2、3、4 的 TX 完成计数 | 四轴各自从 30,001 到 14,430,001，各增 14,400,000 |
| CAN3 ID 2 的 TX 完成计数 | 0 → 0 |
| 末拍核对 | 期望与回显序号均为 14,402,033，四轴新反馈掩码 `0x3c000` |
| 退出状态 | 退出码 0；HPM 回到 PREOP，RK 主站 Idle / inactive |

原始证据：[生产线程窗口统计](../../artifacts/target/irq50-8h-20261123T181007Z-rDH2dtU9/driver/driver-14400000.log)、[起止时间、逐轴前后计数及末态](../../artifacts/target/irq50-8h-20261123T181007Z-rDH2dtU9/console.log)。

## 节拍与相位

| 测点 | 样本与结果 |
| --- | --- |
| HPM 相邻两次 Sync0 中断入口 | 整个 OP 会话 14,400,071 个间隔，最短 1,988 µs、最长 2,012 µs；相对 2,000 µs 为 −12 至 +12 µs |
| HPM 相邻间隔的绝对偏差 | P99 为 3 µs，P99.9 为 4 µs；严格大于 2 µs 的有 1,454,370 个（10.10%） |
| RK 记录的 N+1 到站相位偏差 | 14,400,000 拍相对目标到站时刻为 −2.600 至 +7.663 µs；这是相位误差，不是相邻两拍的间隔 |
| RK 末对 PDO 的实际到站间隔 | 1,999.980 µs，仅代表最后一对；没有全程逐拍到站时标可推算整轮极值 |

HPM 以 1 µs 分辨率统计，范围包含命令窗口外的同步拍。主站释放后，不停核、不复位，[首次读取](../../artifacts/target/irq50-8h-20261123T181007Z-rDH2dtU9/sync0-read.log)和[独立复读](../../artifacts/target/irq50-8h-20261123T181007Z-rDH2dtU9/sync0-crosscheck.log)的直方图分桶一致。表头 `count` 和 `min_us` 异常为零，未用于统计；桶数之和等于独立计数 14,400,072 减一，加权和等于累加器的 28,801,238,048 µs，溢出桶为零。

**适用范围：** 零漏拍说明当次镜像在该拓扑和全零 MIT 负载下满足四轴 N+1，不等于节拍零抖动。HPM 的 ±12 µs 不是物理 Sync0 引脚或各电机 CAN 帧尾的间隔极值。本次不验证带载运动、单路七轴或后续固件。
