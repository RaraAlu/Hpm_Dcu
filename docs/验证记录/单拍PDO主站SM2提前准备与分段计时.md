# 单拍 PDO：SM2 提前准备与发送分段计时

2026-11-19。只改 RK3588 独立零使能探针。A 在第 N 拍起点醒来、准备并发送 SM2；B 在前一拍 SM3 核对完毕后提前准备，等到 N 拍起点才发送。两组均为 CPU6、FIFO 80、锁内存、1 kHz，RK 跟随同一 HPM。SM2 784 B、SM3 1072 B、Sync0 +255 µs、SM3 的 +820/+870/+975 µs 以及 MCU 的 600 µs 构建保护均不变。

## 测量口径

- [探针时序](../../tests/host/ethercat_data/one_cycle_pdo.hpp)：编译时显式设 `DCU_ONE_CYCLE_SM2_PREPARE_US=0` 得到带打点的原路径，设为 `50` 得到提前准备路径。未定义时不启用 SM2 分段记录。前一拍已冻结的 N 拍起点不因迟到而平移；在 N 之前不调用发送。若发送决定已迟至本拍配置的 Sync0 相位，终止该轮，不让已排队的 SM2 随后续 SM3 被发出。
- [IgH 调用](../../tests/host/ethercat_data/production_ready_probe.cpp)：`sm2_entry_ns` 在上拍读回和核对后，`sm2_wake_ns` 在本拍准备开始前；仅当尚未到准备点才会睡眠。两者用于区分「上拍占用了准备窗口」与「调用等待后醒晚了」。准备包括填 PDO、更新 IgH 应用时间；`sm2_prepared_ns` 后才排 DC 报文和 SM2 写域，`sm2_queued_ns` 是入队返回时间。最后记发送调用前的 `write_ns` 和调用返回的 `sm2_send_return_ns`。应用时间按当下时刻换算，不提交未来时戳。同帧 FRMW 来自 ESC，用户态调用时间不是物理上线时间。
- B 的 `50` 是**最多**可提前的时间。前一拍要到 +975 µs 才开始收反馈，因此正常计分时 N−50 µs 已被占用。B 不拆线程、不跳过上拍验证、不重复发包；在剩余时间内填数据、入队，再短暂忙等到 N。逐拍检查上一拍反馈时间不晚于本拍准备入口。

A 最慢的命令 33040：等待返回晚 10.153 µs，准备 0.583 µs，入队 1.167 µs，合计 +11.903 µs。前 32 个通过拍中，这三段中位数分别为 2.483、0.583、1.167 µs；本次短测的额外耗时出现在等待返回，不是排队变慢。B 全部从上一拍读回直接接续，准备入口距离 N 的中位数 17.727 µs；入队后最少仍剩 9.537 µs。该结果是用户态定相发送精度，不代表物理网口或端到端反馈间隔全程 ±1 µs。

## 历史尖峰

[此前的命令 1364947](单拍PDO三十分钟耐久实测.md) 在 +62.831 µs 才进入 SM2 发送调用；其前一拍的有效反馈距本拍起点还有 18.254 µs。这是那批 1,364,502 拍中[唯一达到 50 µs 的调用](../../artifacts/target/pdo-sm2-split-20261119-vA29zJ/prior-incident.json)。可以排除「前一拍反馈本身观察得比本拍起点还晚」，但那次没有 SM2 等待返回、准备完成、入队完成时间戳，不能用本次其他拍的分段数值倒填。

## 原路径三十分钟捕捉

为捕捉相似量级的尖峰，用同一 A 探针二进制另跑完整 1,800,000 拍，**不是 B 的三十分钟验收**。SM2 发送调用偏差 P50 / P99.9 / 最大为 **+3.624 / +7.418 / +19.892 µs**；达到 50 µs 的次数为 0。打点区分出了两种不同来源：

| 场景 | 本拍开始准备前 | 准备 | 入队 | SM2 调用偏差 |
| --- | ---: | ---: | ---: | ---: |
| 命令 4831：确实调用等待后，最晚发出的一拍 | 上一拍已提前 18.131 µs 核对完；本拍等待返回晚 **14.244 µs** | 0.583 µs | 1.167 µs | +15.994 µs |
| 命令 408008：全部拍中的最大偏差 | 上一拍反馈已晚 **17.851 µs**，再过 0.291 µs 才进本拍；**没有调用睡眠** | 0.584 µs | 1.166 µs | +19.892 µs |

全程准备的最大耗时为 1.167 µs，入队最大为 2.042 µs。新证据支持优先查唤醒返回和上一拍占用，而不支持把旧尖峰归咎于常规组包或入队。它不能区分旧故障时的调度、抢占或某次异常 ioctl，也不能证明把发送相位稳定下来就消除了回显超期。

本轮原路径 1,800,000 拍均得到同序号、OP、WKC 1/1，有 **5 拍**在 N+1 截止后才观察到，所以验收是 1,799,995/1,800,000，而不是零漏拍。最小截止余量 −17.851 µs；29:40–29:50 的 10,000 拍全部通过，计分期间 IgH 未记录退 OP 或同步错误。退出后的 SAFEOP 提示另记。见[原路径长测分段](../../artifacts/target/pdo-sm2-split-20261119-vA29zJ/tail-at0/endurance-sm2.json)、[逐拍验收](../../artifacts/target/pdo-sm2-split-20261119-vA29zJ/tail-at0/endurance-n-plus-one.json)和[五拍迟到明细](../../artifacts/target/pdo-sm2-split-20261119-vA29zJ/tail-at0/misses.csv)。
