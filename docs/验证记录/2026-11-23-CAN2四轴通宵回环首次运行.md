# CAN2 四轴通宵回环首次运行

本次计划让当前五轴 Profile 下的 CAN2 四台 7216 各 500 Hz 连续发八小时全零 MIT，目标 14,400,000 拍。使用 RK 生产线程，四轴共享 CAN2，未修改 100 µs 间隔。HPM 使用五轴生产固件，增加了硬件计时；主站逐拍核对 N+1，不因超 1 或 2 µs 单独停发。未自动重启或拼接运行。

**结果：未通过。** 2026-11-23 北京时间约 20:30，实际命令窗口运行约 21.1 秒即结束。RK 调度漏拍 0，提交 10,533 拍，成功匹配 10,531 拍，实测一次 N+1 回显落后一拍；另有一拍在途，非两次已观测的回显失败。CAN2 ID 1～4 的独立 TX 完成计数各从 0 到 10,532；CAN3 ID 2 为 0。监督程序退出码 1，HPM 最终 PREOP，主站 Idle/inactive。

| 指标 | 实际结果 |
|---|---|
| RK 从站 DC：N+1 相对目标到站偏差（10,532 个样本） | −0.943 至 +2.684 µs，峰峰值 3.627 µs |
| 到站绝对偏差严格大于 1 µs / 2 µs | 4 拍 / 4 拍 |
| HPM 锁存到成功写完 SM3（10,531 个完整样本） | 最小 1,223.958 µs，最大 1,587.958 µs，峰峰值 364.000 µs |

HPM 使用同一 24 MHz machine timer 的低字：Sync0 ISR 取得本拍 SM2 槽后打点，成功写入 ESC SM3 后取终点。两次读取的无符号差值不受单拍内计数器回卷影响。只对同一 epoch、反馈已齐且确认发布成功的周期计入极值；失败拍不作为慢样本或零值混入。原始统计六个小端 uint32 依次为时钟频率、样本数、最小 ticks、最大 ticks、首尾 epoch：`24000000, 10531, 29375, 38111, 63, 10593`。

失败时 N+1 期望 13075，实读 13074；即便四轴有效位仍在，也不是所需命令的反馈。HPM 同一会话记录最后锁存槽序 10594、最后发布 epoch 10593，故障位 `0x04`（TX_LATE），缺 CAN 设备掩码为 0。单次会话最大耗时不能归因到失败拍；这些证据不能进一步区分是 CAN 完成较晚、打包较晚还是 ESC 写入预算耗尽。连续命令下同一到站帧也是下一命令帧，故障行的两个当前缓存 DC 时间相同，不代表两次以零间隔发帧。

证据：[监督程序输出及 TX 计数](../../artifacts/target/20261123T122936.734150Z/通宵测试/supervisor.log)、[生产线程日志](../../artifacts/target/20261123T122936.734150Z/通宵测试/run/driver-14400000.log)、[HPM 回环原始计数](../../artifacts/target/20261123T122936.734150Z/通宵测试/latency.bin)、[HPM 周期故障快照](../../artifacts/target/20261123T122936.734150Z/通宵测试/cycle.bin)。硬件统计在 PREOP、RK 主站释放后读取，期间未复位，读后已恢复 CPU。

## 原故障现场补读

同一 boot ID `0x14800000000` 下，RK 主站 Idle、从站 PREOP 时保存了[原生产流水线 RAM](../../artifacts/target/20261123T122936.734150Z/首故障保留现场/pipeline.bin)。槽 0 的线序号是 13075，槽序号和 epoch 均为 10594；该槽 SM2 完整就绪为 55143835 µs，Sync0 锁存为 55144070 µs，提前 235 µs 就绪。工作线程的 pending、processed epoch 都是 10594。本拍 cyclic_active=1、cyclic_epoch=10594、cyclic_missing=0；这不同于仅查看 SM3 里上一拍的四个有效位。它说明命令已处理，四轴本拍反馈最终都被网关匹配，不是某台电机始终未应答。

本拍 SM3 截止为 55145670 µs（Sync0 + 1600 µs），而软件故障处理记录为 55145733 µs（截止后 63 µs）。published=0，published_epoch=10593，faults=TX_LATE。**63 µs 是故障处理相对截止的时间，不是 SM3 写入耗时或超期量**。原镜像不保留这一拍的收齐时刻、打包边界或最后一个 ESC 字的提交结果；当前证据不能再细分。RX 环是可复用队列，补读时已包含后续流量，不能把那些 CAN EOF 归给 13075。
