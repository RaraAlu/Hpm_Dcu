# CAN1、CAN2 两轴 500 Hz 六十秒回环

**通过。** 沿用[单拍测试](2026-11-25-周期整改后两轴单拍.md)的 HPM 固件、RK 生产 DriverModule 和接线。未复位、未烧录、未重复单拍；本次只启动一次 30,000 拍窗口，不重试或补拍。

| 判据 | 实测 |
| --- | --- |
| 连续全零 MIT | 周期 2,000 µs，发送 30,000 拍；从首发到最终读回 60.002037 s |
| 逐拍 N+1 | 30,000/30,000 两轴均匹配，RK 调度漏拍 0；末拍命令与接受序号均为 31851，新反馈掩码 `0x4080` |

生产线程检查每个到期命令的接受序号、发布序号推进和目标轴新反馈；监督程序只供给全零命令并核对窗口和前后计数。不是仅凭末拍掩码或 WKC 判断整段通过。

开始前在 PREOP 核对双向映射：槽 7/14，SM2/SM3 144/160 B，代次 3。结束后在同一启动编号 `0x0000019800000000` 下恢复原完整布局，SM2/SM3 248/296 B，代次 4。最终 HPM PREOP、RK Idle/inactive，透传配额和所有权均为 0。未继续更长耐久或同总线多轴测试。
