# 静态 Profile 重连实板验证

结论：**生产 Release 在空载台架上通过普通 PDO 启动和同 Profile 重连。** 未发送专用确认帧、未写会话号、未写旧配置 SDO。电机动力物理隔离，CAN 未接业务节点。

| 验证项 | 实板证据 |
| --- | --- |
| READY 与布局 | IgH 在进 OP 前读到启动代次 21、READY、会话保留字段为 0。Sync0 周期 4 ms，PDO 工作计数完整（2）；RxPDO 784 字节、TxPDO 1072 字节。 |
| 首次启动 | 故意先发普通带板级使能但无设备使能的 PDO，确认序号始终为 0。随后发普通零使能 PDO 建立基线 101，正常推进至 121。序号 121 带板级使能，但通道、设备掩码和 Raw 批次均为空，不触发实际外设动作。 |
| 重连与重放 | 释放 IgH 再连接，启动代次仍为 21，READY 代次由 9 变为 13。重发上一轮序号 121 的带板级使能帧不能建立基线；发送普通零使能 122 后，再发原 121 也不被接受，随后新序号正常推进至 142。后半段重放与新鲜零使能帧交错，避免把租约超时误当成旧序号拒绝。 |
| 收尾 | 探针退出后 IgH 为 Idle/未激活，MCU 回到 PREOP/READY，已接受序号及保留字段均为 0。最后一次周期诊断故障位为 0，PDO 发布最长 380 µs；随后暂停 MCU。 |

烧录前已备份并校验 SII 64 KiB 和启动日志 8 KiB。镜像擦除边界不进入保留区；最终 SII 与原备份一致，启动日志保留既有记录并递增到 21，没有重新初始化或写回旧日志。

实板使用[空载 IgH 探针](../../tests/host/ethercat_data/production_ready_probe.cpp)，仅检查电机槽配置为空的生产镜像；未部署或启动完整 DriverModule。结论不覆盖真实 CAN 设备、执行器重新使能、物理拔线或长时间实时性。
