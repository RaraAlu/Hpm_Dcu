# 生产网关一次确认实板复测

结论：**生产 Release 镜像通过空载实板 READY、一次确认、会话 PDO 和重连旧数据拒绝。** 电机动力隔离，CAN 未接业务节点；不据此验收外部 CAN 收发、实际设备自检、物理拔线或启动耗时。

| 验证项 | 证据 |
| --- | --- |
| 调度恢复 | 在生产构建的 FreeRTOS 上下文恢复中，返回非临界任务时清除残留 PLIC 阈值；嵌套 ISR 和临界任务仍用 SDK 保存的阈值。不改 BSP、SDK 源文件或中断优先级。 |
| PDO 发布 | 两种构建均曾触发 `TX_LATE`。将准备窗口由 100 µs 提前至 600 µs，截止点仍为下一次 Sync0 前 250 µs。通过复测的 Release 镜像记录发布耗时最大 372 µs、周期故障位 0。 |
| 自主 READY | RK3588 上的 IgH 读到生产从站身份，首轮进入 OP 前读到启动代次 18、READY 代次 1、未激活。 |
| 一次确认 | 空载探针进入 OP，Sync0 周期 4 ms，工作计数完整，RxPDO 784 字节、TxPDO 1072 字节。无确认时接受序号保持为 0；只发一帧确认，得到会话低位 1，有效会话的空载 PDO 确认到序号 20。 |
| 会话撤销与重连 | 主站释放 IgH 后重新连接，同一启动代次的新 READY 代次为 3。旧确认和旧 PDO 拒绝；再确认一次得到会话低位 2；旧会话 PDO 在新会话运行时仍被拒绝。 |
| 收尾 | 停止探针后读到 PREOP、READY、会话 0，IgH 为 Idle/未激活；随后暂停 HPM。SII 与备份逐字节校验一致，未重新初始化日志。 |
