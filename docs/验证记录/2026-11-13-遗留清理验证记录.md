## 边界与代价

旧生成器和输入材料已删除，当前完整 ENCOS 生成链仍不可用。后续改协议时需从 Git 历史调查真实来源、恢复可解析生成器并在隔离目录比对，不能仅依据现存 ESI 或编译成功宣称可再生成。当前可读 SII 工具仍未验收 PowerShell/Beckhoff 运行环境。
