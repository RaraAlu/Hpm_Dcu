# 单拍 PDO：主站 SM3 等待返回与醒后处理复测

2026-11-19。接续[主站跟随参考时钟的实板对照](单拍PDO主站跟随参考时钟与Sync0硬件捕获.md)。短测 32/32 通过后才开始长测；长测 **60,000/60,000 拍按时同序号回显**，没有漏拍。本轮最慢的 SM3 发送调用主要晚在定时等待返回，不在醒后处理。

## 逐拍验收

| 1 kHz 测试 | 成功 / 实发 | 截止前未读到对应反馈 | 每个计分拍的最终状态 |
| --- | ---: | ---: | --- |
| 短测 | 32 / 32 | 0 | OP，SM2/SM3 WKC 1/1 |
| 60 秒长测 | 60,000 / 60,000 | 0 | OP，SM2/SM3 WKC 1/1 |

长测命令从 454 到 60,453 连续；每个命令都在发送前已确定的 N+1 截止前取得有效回显。最小截止余量为 **3.057 µs**（序号 53,688）；最后一拍也正常返回，余量 17.997 µs。IgH 日志有 SM3 域中间态 WKC 变化；探针在同一次已发读请求上轮询，计分取本拍截止前的有效结果，不宣称每次中间轮询均为 1/1。退出时主站释放后记录了 SAFEOP + ERROR，最终 PREOP，与计分期间分列。

## SM3 分段

计划点是当拍 RK 唤醒基准加 870 µs。等待返回取 `sm3_wait_return_ns`（用户态定时等待返回后的第一个时间戳）；随后处理 SM2 回包、检查输出域、排队 SM3，直到 `read_ns`（调用 SM3 的 `ecrt_master_send()` 前）。均为同一 RK 单调时钟；后段不包含发送调用本身和线上传输。

| 段（µs） | 长测中位数 | 长测 P99.9 | 最慢发送拍之前 32 拍中位数 | 最慢发送拍（序号 6350） |
| --- | ---: | ---: | ---: | ---: |
| 计划点 → 等待返回 | 4.039 | 7.179 | 5.168 | 13.557 |
| 等待返回 → SM3 发送调用 | 4.958 | 5.833 | 4.959 | 5.250 |
| 计划点 → SM3 发送调用 | 8.955 | 12.345 | 10.311 | 18.807 |

序号 6350 相对相邻正常拍，等待返回多用约 **8.39 µs**，醒后处理仅多 **0.291 µs**。各段中位数独立计算，不要求加总后等于总时长的中位数。此拍发送调用在 +888.807 µs，反馈在 +988.853 µs，有效且距截止尚有 11.129 µs。

按总时长取最慢的 60 拍（0.1%），逐拍分别与其前 32 个成功拍的分段中位数比较：**57 拍是等待返回的增量更大，3 拍是醒后处理的增量更大**。优先排查等待到期至用户态恢复运行；本轮未区分定时器到期、线程就绪、上 CPU 或抢占。此前的 +35.996 µs 超时没有复现，当时也没有等待返回打点，不能把旧超时直接归因于晚醒。

## 条件与证据

- 同一份带时间戳的独立探针，两轮同一 MCU 启动号 104。CPU6 隔离、FIFO 80、锁内存，进入测试前无其他可迁移任务或有效设备 IRQ 使用 CPU6，结束后恢复临时线程亲和设置。仅使用 RK 跟随 HPM 模式，长测 60,000 拍均有有效同帧参考观测。
- 普通 PDO 零使能，SM2 784 B、SM3 1072 B。Sync0 +255 µs、发布提前 399 µs、构建保护 600 µs；不接 CAN、不写 Profile、不改布局、不启用生产 DriverModule。固件与上一轮镜像回读一致，未烧录；未读 GPTMR 捕获数据、未做 Sync0 精度专项测试。主站 Idle、从站 PREOP 后暂停 HPM，SII 终检一致。
