## 验证范围

- 协议生成器从 JSON 重建对象与 ESI；只读一致性检查通过。生成的 C 与 C++ 编译期断言固定 88 B 及全部 75 个字段的偏移，包括最后一个字节。四档的双向长度分别断言；默认 SII 映射分类及旧线协议的校验值不变。
- 端到端宿主用例 `single_fd` 走生产 Profile 初始化、CoE 请求与复位、assignment、OP、SM2 解码、网关提交和 SM3 发布；替代的是 ESC/CAN 硬件。验证 DLC 15 的 64 B 双向逐字节一致，模拟站址 0x1234 得到匹配号 0x34，两帧分两个周期取出，空批、非法 mask/count、重复序号、过期、故障清零和 88 B 镜像边界。旧双槽与七槽档继续运行各自回归。
- `cmake --build --preset hpm-debug` 与 `hpm-release` 链接成功，均通过镜像边界检查。宿主全量使用 Unicorn 2.1.4，403 项，400 通过、3 项因缺少 `.openidea/settings.toml` 未通过，无跳过。协议生成 16 项、头文件归属 7 项均通过。
- 未烧录，未访问 ESC 或 CAN 硬件。文档中的 100 Mbit/s 数值仅为净载荷串行化计算，不是 HPM 发布耗时、RK 周期抖动或 500 Hz 闭环验收。
