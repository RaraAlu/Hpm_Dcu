# 完整 PDO 回环逐拍验证

RK3588 独占 IgH，使用 CPU 4、SCHED_FIFO 80、`mlockall`，以 1 ms 主站周期和 1 ms Sync0 运行 60000 拍。HPM 沿用板上已有的捕获版 Release，不重新烧录。主站一直发送零使能 PDO，通过现有 RxPDO 命令序号与 HPM 固件在 TxPDO 发布的接受序号一一配对；不接 CAN，不下发 Profile 或重配 PDO。试验前后读回活动 Profile ID/版本为 1/1、无候选、命令租约 10 ms、就绪 TTL 1000 ms、启用设备掩码为 0。

只统计 60 秒窗口内发送的命令。窗口后继续发 24 拍零使能 PDO，收齐此前在途的反馈，尾段新发的命令不计入样本。只有 OP 且 WKC 完整时观察到的新接受序号才算完成。

| 指标 | 实测 |
| --- | --- |
| 完成数 / 漏拍 | 60000 / 0；无重复观测、乱序或异常 AL/WKC |
| 完成间隔 | 990.798 至 1010.340 µs，偏离 1 ms 为 -9.202 至 +10.340 µs |
| 完成间隔绝对误差 | P50 0.423 µs，P99 3.077 µs，P99.9 6.577 µs |
| 超出 ±1 µs | 6226 / 59999 个间隔，约 10.38%，未达到全程 ±1 µs |
| 单次回环延迟 | 2.987 至 3.010 ms，中位数约 3.000 ms；所有反馈均在命令发出后第 3 个主站周期被读取 |

时间戳取自主站的同一个单调时钟：发端在 IgH 周期发送调用前，收端在接收、处理 IgH 域并读取 TxPDO 接受序号后。完成间隔包含主站线程唤醒、接收和应用读取的影响，不是物理网口间隔，也不是片内 Sync0 抖动。测试结束从站回到 PREOP，AL 状态码为 0，IgH 为 Idle。
