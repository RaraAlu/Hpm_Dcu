# 动态 Profile 策略实板验证

生产 Release 在空载台架上通过了策略暂存、提交、生效和 MCU 复位回退。测试使用 RK3588 IgH 的 CoE 命令及空载 PDO 探针，未部署完整 DriverModule；电机动力已隔离，CAN 无业务节点。

| 验证项 | 实板结果 |
| --- | --- |
| PREOP 暂存 | 启动代次 24，固件预置版本 1。下载版本 2 后，活动版本仍为 1，三项策略仍为 10 / 20 / 1000 ms。 |
| 一次提交 | 活动版本变为 2，PDO 租约上限、反馈超时、就绪 TTL 分别为 8 / 15 / 750 ms；READY 代次由 1 变为 3。重复提交版本 2 不再次准备。 |
| 普通 PDO 生效 | 4 ms Sync0 下进入 OP，WKC 为 2；RxPDO 784 字节、TxPDO 1072 字节均不变。零使能之前应答为 0；租约 10 ms 的命令被拒，租约 8 ms 的普通 PDO 通过，应答序号推进到 121。 |
| 未提交候选隔离 | 另行暂存版本 3，不提交就进入 OP。在回到 PREOP 后，活动版本仍为 2，待提交版本已清空，结果为已取消。 |
| 主站断开再启动 | MCU 未复位，PREOP/READY 读回仍为版本 2、8 / 15 / 750 ms，未重发任何配置。两次后续循环探针均未稳定进入 OP，重连后的 PDO 恢复未验收。 |
| MCU 复位 | 启动代次升至 26，自动回到 READY 和预置版本 1，读回 10 / 20 / 1000 ms。重发启动代次 24 的有效候选，收到 SDO 拒绝 `0x06090030`，活动策略不变。 |

第一次重连失败后，MCU 的周期快照读到 `TX_LATE`，PDO 发布最长 649 µs，高于 600 µs 准备预算。未放宽截止保护，也未把 WKC 完整当作进入 OP 成功；生产重连的实时性仍需复测。

后续定位与结果见[主站重连发布超时实板复测](2026-11-18-主站重连发布超时实板复测.md)。

烧录及后续复位前均备份了 SII（64 KiB）和启动日志（8 KiB）。最终 SII 与初始备份一致，启动日志旧记录保留且递增到 26；策略本身不落 Flash。收尾时 IgH 已退回 Idle，HPM 留在新版生产 Release 并由 J-Link 暂停。

离线：Debug、Release 编译及镜像保护检查通过；主机回归 340 项，335 通过、5 跳过。生成回归确认 PDO、原 SDO 描述符和 SII 不变，仅新增独立的 `0x2100` 对象。未验收真实 CAN 节点、反馈超时或就绪 TTL 的实板触发、执行器动作、物理拔线或长时间周期稳定性。

证据目录：`artifacts/target/20261118T124440.900396Z/`。主要日志为 `policy-stage-commit.log`、`policy-pdo.log`、`policy-reconnect*.log`、`policy-after-reset.log`、`policy-final-paused.log`。操作与字段见[动态 Profile 策略事务](../当前说明/动态Profile策略事务.md)。
