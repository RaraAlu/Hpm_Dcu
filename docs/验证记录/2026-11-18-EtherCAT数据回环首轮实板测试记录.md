# EtherCAT 数据回环首轮实板测试记录

日期：2026-11-18。**独立诊断镜像通过线上 SDO 只读与 PDO 逐字节回环。** 主站为 RK3588 上的 IgH，只启用 `DriverModule`。电机动力已物理隔离，无 CAN 业务节点，EtherCAT 专用口仅连这块 HPM。

| 阶段 | 观测及结果 |
| --- | --- |
| 备份与烧录 | 先 halt 读回 64 KiB Flash 保留区，再复位、校验并下载冻结版 `hpm-ethercat-data`；烧录校验通过，擦除范围未进入保留区。启动后不中断 SII 服务。 |
| 链路与从站 | Link UP，单从站 `PREOP`，Vendor `0x00010000`、Product `0x7fff0002`、Revision `1`，CoE 邮箱各 128 字节。 |
| SDO 只读 | 在 PREOP 完成 36 项上传核对，含身份、长度、`0x2101:00` 的 12 字节 `01 23 45 67 89 ab cd ef 00 ff 5a a5`，以及固定赋值和 20 个映射条目。不走旧逐项 SDO 下载流程。 |
| PDO 映射 | SM2/RxPDO：ESC `0x1100`、32 字节，IgH 域偏移 0–31；SM3/TxPDO：ESC `0x1200`、48 字节，IgH 域偏移 32–79。20 个条目均为 32 位，位偏移均为 0。 |
| PDO 数据 | 诊断从站在 OP、WKC 完整且为 3 时，`00..1f`、全零和全 `ff` 三组逐字节相等，新样本计数分别为 3、5、7。每组均通过长度 32、布局版本 1 和有效标志 1 的校验。 |
| 收尾 | 主站回到 Idle / Active: no，从站回到 PREOP，AimRT 进程退出；MCU 暂停前 AL 状态为 `0x2`，状态码 `0x0`，样本计数与有效标志归零。Flash 保留区前后逐字节一致。关闭调试服务，保留诊断镜像，未恢复生产固件。 |

首次启动 AimRT 未载入远端 shell 的 ROS 环境，因缺少 `librosidl_typesupport_cpp.so` 在加载模块时退出，尚未执行 SDO。用远端已配置的 ROS 环境重跑后通过。两套探针成功后由外层 `timeout` 结束空闲 AimRT 进程，退出码 124 本身不是探针错误。

本次只验收 EtherCAT 到 MCU 内存的诊断通路。不覆盖 CAN、生产 Profile、一次确认启动耗时、长稳或实时性。
