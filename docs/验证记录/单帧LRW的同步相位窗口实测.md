# 单帧 LRW 的 DC Sync0 相位窗口

2026-11-19，HPM / RK3588。验收配置为 1 kHz、单个 1072 B LRW（SM2 下行 784 B、SM3 上行 1072 B，逻辑地址重叠），只启用 DriverModule，CPU6、FIFO 80、锁内存、RK 跟随 HPM。不接 CAN，不以回包或命令回显验收。固件、Profile、PDO 布局、600 µs 构建预算不变；板卡原诊断镜像的发布提前量仍为 399 µs。

## 离线定窗口

用关闭打印的 HPM 片内记录检查 SM2 提交，并补上此前原生帧记录中的较差样本。对 128 对有 FRMW 时间戳的 LRW，使用 SM3 发布后同时记录的 HPM 微秒计时和 ESC DC 时间，把发布时刻放到帧时间轴上。按物理帧和实际 Sync0 配对，不按“最终被锁存的内容”推断该帧的目标 Sync0，也不强制任何同拍应答。

| 旧相位 +255 µs 的观测 | 最小余量 |
| --- | ---: |
| RxPDO 提交完成到目标 Sync0，关闭打印的 30 样本 | −10 µs |
| 计入原生逐帧记录后的 RxPDO 保守取值 | −61 µs |
| TxPDO 实际发布到下一帧的 FRMW 时间戳 | 465.34 µs |
| 即使发布卡到固件硬截止，到下一帧仍有 | 177.42 µs |

相对旧值增大相位会增加 Rx 余量，但等量消耗 Tx 余量。每边预留 10 µs 做时间轴对齐与波动保护，另要求 25 µs 正余量，用硬截止而非较乐观的发布实测限制窗口上沿，算得 **+351～+397.42 µs**。选择近中点 **+375 µs**，带测量预留的离线预测为 Rx 不低于 49 µs，Tx 即使卡到截止仍不低于 47.42 µs。这个结论只适用于板上 399 µs 发布提前量的镜像；默认 250 µs 的 Release 参数不应直接套用本窗口。

## 实板门槛

用原镜像、相同 FMMU 重叠映射，关闭逐帧十六进制打印。新增记录的是已经采到的 FRMW 参考时刻和本拍 DC 网格，不增加任何 PDO 发送。32 拍每拍发 1、收 1、WKC 3、OP，HPM 各拍均在目标 Sync0 锁存正确的槽。RxPDO 最小提交余量 116 µs；有后继帧的 31 对最小实际 TxPDO 发布余量为 347.22 µs，扣预留后的全段硬截止下界为 46.38 µs。最后一拍无下一帧可比；停发后下一边沿的缺槽不计入测试窗口。

## 60 秒结果

32 拍门槛通过后，暂停取片内记录、直接恢复时邮箱只读检查失败，未启动计分。用 J-Link 的硬件复位恢复同一镜像，重新只读确认 READY 和 Profile，随后连续跑一组 60 秒；没有补帧、拼接或调整相位。

| 项目 | 结果 |
| --- | ---: |
| 实际发送 / 收到 | 60,000 / 60,000 |
| 每拍 1 发 1 收、WKC 3、OP | 60,000 / 60,000 |
| 末尾 HPM 环形记录：同拍 RxPDO 提交到 Sync0 | 128 拍均匹配，最小 116 µs |
| 末尾有下一物理帧的实际 TxPDO 发布余量 | 127 对，最小 353.26 µs |
| 按全程每帧 FRMW、对齐后的 DC 网格、固件硬截止计算（含 10 µs 预留） | Tx 下界 46.18 µs |

HPM 的提交和发布详细时间戳只留末尾 128 项，不能把样本最小值说成全程逐拍直接测量。固件累计锁存 60,016 个槽（含本次 16 拍稳定预热）；其中 **读完 ESC** 到 Sync0 的最小值是 119 µs，不等于原子发布或提交函数返回的余量。计分期间没有重现提交晚到或 WKC 掉到 1；停止发 PDO 后的下一边沿记录了预期的缺槽，不算漏拍。

主站退出到 Idle，从站 PREOP，CPU 掩码恢复，HPM 已暂停。已回读核对诊断固件和 SII 不变；未烧录、未擦除或重置启动日志。

## 3 µs 抖动补算

用已存逐拍记录相减：相邻拍的 `rx_ns` 间隔减 1 ms，再取绝对值。这个采样点在 RK 完成 IgH 接收、域处理和读 WKC 后，但在 AL 核对和反馈复制之前。它是单帧路径上的完成间隔代理，不是此前双帧探针的逐拍回显确认时刻，也不代表从站的 Sync0 抖动。

| 计分窗口 | 相邻间隔 | P99.9 | 最大绝对偏差 | 超出 ±3 µs |
| --- | ---: | ---: | ---: | ---: |
| 32 拍 | 31 | 2.170 µs | 2.170 µs | 0 |
| 60 秒 | 59,999 | 2.817 µs | 6.871 µs | 49 |

因此 60 秒的通信门槛通过，但**完整收发间隔并非全程在 ±3 µs 内**。同一窗口，RK 调用发送的间隔最大偏差 0.484 µs，HPM 侧 FRMW 到达时标间隔最大偏差 1.480 µs；最大完成间隔尖峰发生在序号 8350 至 8351，收取完成相对计划时刻的额外延迟从 13.291 µs 降到 6.464 µs。现有数据把调查范围收窄到 RK 收取一侧，尚未分开唤醒、IgH 接收和域处理。
