## 需求与范围

用户采纳 DC、Sync0、一拍反馈流水线和 RTOS，Sync0 暂定 200–1000 Hz，目标是 DCU PDO 锁存抖动 1 us，不扩大为电机执行同步。按用户要求先完成从站，指定的 `driver_module` 仅作只读接口参考，主站后续共同调整。

当前时间契约及故障策略见[周期锁存与反馈发布契约](../当前说明/周期锁存与反馈发布契约.md)，待测项见[项目总计划](../设计资料/项目总计划.md)。

## 实施内容

| 项目 | 实现 |
| --- | --- |
| 周期配置 | 读取 ESC `0x09A0`，校验闭区间 1–5 ms；要求 DC Sync0，拒绝非 DC、Sync1 和 OP 中热改 |
| RxPDO | PDI 复制完整映像；三缓冲、32 位无锁原子所有权；Sync0 快路径只锁存，不整块复制、解析或发送 |
| RTOS | SDK 配套 FreeRTOS V10.5.1；一个静态业务任务和内核 Idle，关闭 Tickless 和内核动态分配 |
| 状态归属 | SSC 后台、完整 Sync 处理、看门狗、SDO 与电机状态同属业务任务；移除电机大范围全局关中断 |
| 中断交接 | Sync0 优先级 5，PDI 为 4，内核屏蔽边界为 3；快中断不调用 RTOS API；PDI 不重复分派 Sync 事件 |
| 本地时间 | GPTMR1 通道 0，1 MHz 自由计数；快路径不再调用 64 位除法或 Flash 中的时钟查询 |
| TxPDO | 去除固定 2 ms 缓存门限；按周期构建完整快照并写 ESC，默认提前 250 us，构建预算 100 us |
| 故障 | 缺帧、快照积压、发布超期、失步和配置热改锁存故障；业务任务请求 SAFEOP/SYNCERROR，复用无效 PDO 故障位 `0x40` |
| 独立门控 | GPTMR2 每 50 us 唤醒并检查周期；业务任务卡住时仍可禁止新 CAN TX、取消排队请求，不并发修改电机状态 |
| Flash | SAFEOP/OP 拒绝 SII 写入和刷新；PREOP/INIT 处理延迟脏页，保留初始化和原 EEPROM 保留区保护 |
| 协议 | 三种 PDO 字节布局、现有反馈新鲜度和接口版本保留；不再生成 ESI/SII，不新增 OD 对象 |

## 离线验证

执行入口：

```bash
cmake --preset hpm-debug
cmake --build --preset hpm-debug --clean-first
cmake --preset hpm-release
cmake --build --preset hpm-release --clean-first
python3 scripts/dcu.py test
ctest --preset hpm-debug
git diff --check
```

完整清理重建与最终修改的增量复验均通过；两个配置分别有 86 个编译单元，其中 6 个 C++。原 SSC 地址比较、位掩码窄化、packed 成员和 Release 邮箱数组边界警告仍在，没有通过全局屏蔽警告来消除。

提交前另通过统一入口 `python3 scripts/dcu.py build --preset hpm-debug` 和 Release 对应命令复验配置、增量构建及镜像保护，两者均无需重新编译，不记为新的全量重建。自研代码与文档的暂存区空白检查通过；导入依赖的 9 处上游原有行尾空白已逐字节核对并保留，不为通过格式检查修改锁定源码。

本机日志保存在 `artifacts/offline/2026-11-16-sync0/`，属于不入库的验证产物，不是构建输入。

离线测试共 **98 项**，包含原有 71 项及本轮新增 27 项：

| 测试 | 数量 | 证据边界 |
| --- | --- | --- |
| PDO 纯核心 | 11 | 周期范围、整帧交接、最新完整帧、读缓冲保护、缺帧、积压、截止、时间采样被抢占、回绕与重置 |
| 生产周期运行代码 | 9 | 配置/启动拒绝、ISR 仅交接、任务发布、打包加 ESC 写入超期、跨拍、缺帧、失步、热改和任务停滞门控 |
| 生产电机状态代码 | 5 | 同毫秒多次构建、快照只读与新鲜度、三种 PDO 边界、周期故障清会话、无效 PDO 不能抑制 STOP |
| 内核依赖与配置 | 2 | 38 文件摘要、内核版本、静态分配和 IRQ 配置契约 |

运行测试直接编译生产 `cycle_runtime.c`，但替换了 RTOS、SSC 函数和外设。电机状态测试直接编译生产 `motor_control.cpp` 及真实协议/驱动绑定，使用真实 SSC 类型、生成存储和替代 CAN I/O；宿主按 `-O0 -Wall -Wextra -Werror -pedantic-errors` 检查，另有目标 Debug/Release 构建。测试没有运行真实 FreeRTOS 调度器、HPM 外设或整套 SSC 状态机，不能推出硬件实时性结论。

镜像保护检查通过：

| 配置 | FLASH 链接占用 | ILM | DLM | AXI SRAM | 擦除范围，右端不含 |
| --- | --- | --- | --- | --- | --- |
| Debug | 326440 B | 18888 B | 35232 B | 129864 B | `0x80000000..0x8005f000` |
| Release | 303944 B | 22344 B | 35232 B | 129856 B | `0x80000000..0x80059000` |

AHB SRAM 两者均为 10240 B。上述 FLASH 为链接器区域统计，不是整个物理擦除跨度；保留区 `[0x80080000,0x80090000)` 未被任何检查出的加载/擦除跨度覆盖。当前 ELF 摘要和物理段见各自 `build/<配置>/image-check.json`，其中 `hardware_geometry_verified=false`，本轮未重新探测 Flash 几何。

反汇编检查确认 `pdo_pipeline_sync`、`pdo_pipeline_fault`、`dcu_cycle_sync0_isr` 和 `dcu_cycle_now_us` 位于 `.fast`，三缓冲位于 `.fast_ram`；ISR 入口由 SDK 放入 ILM 的向量段。时间读取是 32 位定时器寄存器访问，快速调用链不包含 RTOS API 和 64 位除法。这证明链接位置及代码形态，不证明外部事件到锁存的延迟。

## 未验收事项

1. FreeRTOS 板上启动、抢占/浮点上下文、IRQ 嵌套与任务/中断栈水位。
2. 外部 Sync0 参考到真实锁存生效的延迟、峰峰抖动及最坏屏蔽上界；1 us 仍是目标。1 MHz 本地时间戳不能作为足够分辨率的独立测量证据。
3. 1/2/5 ms 和中间周期在真实 PDO/CAN/SDO 负载下的截止、吞吐、反馈年龄，以及 250/100 us 初值是否足够。
4. 退出 OP、严格缺帧、断链、主站停发、任务停滞、Bus-off、反馈超时、STOP/重置和重新使能的真实状态转换。
5. 一拍窗口保证的是完整反馈快照，不是全部轴已经执行本拍命令；主站发帧相位、读取与消费时刻后续共同对齐。
6. 取消 TX 请求不撤销已经上总线的帧，不保证电机立即物理停止；断言、CPU 暂停、全局关中断和硬故障仍依赖独立安全措施。
7. 旧 ESI 残留非 DC 模式，本固件拒绝该生产配置；若要更新协议交付物，需单独恢复并验收生成链，不能只改 XML。
