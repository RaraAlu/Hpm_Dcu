# 回环周期与布局锁存实板对照

IgH 探针将主站周期、发送间隔与 Sync0 一起调整。每轮新建主站会话，用空载 Profile v1 发送普通零使能 PDO，核对 OP、WKC 和应答序号。只读 Profile，不下发或提交，也不改 CAN、PDO/SDO 布局、600 µs 准备预算或 250 µs 发布提前量。

每个完整压力轮约 4 秒：4 ms 用 1000 帧，2 ms 用 2000 帧，1 ms 用 4000 帧。应答滞后上限是探针的检查条件，不是固件保护：4/2/1 ms 分别取 3/4/6 拍。先等待第一份零使能应答，再检查已有应答不能倒退或超出上限；每拍仍要求 OP 和 WKC 完整。1 ms 的实测正常滞后为 4 拍，所以沿用原 3 拍判据会误判。

| 对照 | 结果 |
| --- | --- |
| 旧版 1 ms | 首次进入 OP 后未完成应答验收；重试未稳定进入 OP。J-Link 快照见 `RX_MISSING`。 |
| 新版 4 ms | 前两轮各通过 1000 帧；第三轮未稳定进入 OP，读到 `RX_MISSING`，未见 `TX_LATE`。相同周期下，上版到新版的打包段最大耗时由 42 降到 23 µs，SSC 发布段由 155 到 158 µs，打包到发布完成由 192 降到 177 µs。 |
| 新版 2 ms | 第一轮通过 2000 帧，WKC 为 2，应答最大滞后 3 拍；第二轮未稳定进入 OP，读到 `RX_MISSING`。打包段、SSC 发布段和打包到发布完成分别为 19 / 149 / 166 µs。 |
| 新版 1 ms | 复位后前两轮各通过 4000 帧，WKC 为 2，应答最大滞后 4 拍。第三轮在周期索引 447 处 WKC 降为 1；该轮主站唤醒延迟最大 901 µs，退出后读到 `RX_MISSING`。本次最大打包到发布时间 440 µs，不是 `TX_LATE`。 |

耗时是各阶段观测最大值，不能相加；1 ms 旧版未完整跑完，不把不同长度的最大值用作性能对照。主站唤醒延迟与低 WKC 同轮出现，不足以确定缺帧原因。

布局锁存减少了打包时间，但三种周期都未通过重复重连的完整验收。下一步需要对齐记录主站发帧、PDI 收帧、Sync0 和退出 OP 的时刻，区分主站退出时断流、回环中丢帧和从站收帧时序问题，不放宽保护。

烧录前已备份 SII 和启动日志；结束时 SII 回读一致。启动日志从 45 递增到 55，按日志自身规则在 48 正常换扇区，烧录前所在扇区的记录保持一致。IgH 为 Idle，从站回到 PREOP，HPM 保留布局锁存 Release 并暂停。主机回归 343 项，338 通过、5 跳过，探针在 RK3588 以 `-Werror` 编译。
