# 周期整改后 CAN1、CAN2 两轴单拍

**通过。** 生产 `DriverModule` 在 500 Hz 下只发一拍全零 MIT：CAN1 ID 1 和 CAN2 ID 1 在 N+1 均有本拍新反馈，各自的 TX 完成计数增加 1。没有重试或转长测。

| 项目 | 实测 |
| --- | --- |
| HPM | `hpm-release-five-axis`，逐轴采样开启；ELF SHA-256 `9a1ac9d9bc45f06078c64eb6e32e4bde4d9af91933d1b4691efa39b75790e34d` |
| PREOP 核对 | Profile 1 / rev 12，本次构建的契约；两轴槽 7、14，掩码 `0x4080`，SM2/SM3 144/160 B，IgH 域 304 B |
| N 与 N+1 | 命令序号 1588、接受序号 1588、发布序号 36045、新反馈掩码 `0x4080`；发送 1、匹配 1、漏拍 0 |
| 独立 TX 完成计数 | CAN1 ID 1、CAN2 ID 1 均为 0 → 1。恢复完整布局后，CAN2 ID 2/3/4、CAN3 ID 2 仍各为 0 |
| 结束 | 同一 boot ID `0x0000019800000000`，PREOP 下恢复原完整布局 248/296 B，代次 2；RK Idle/inactive，透传配额和所有权均为 0 |

首次保护事务在写 Flash **之前**停止：复位前备份后，旧固件在原空槽追加了合法的下一条启动记录 `0x192`。保留这份备份，改用常规受保护事务复位后备份，两份 SII 内容相同；启动日志相差两条连续追加记录 `0x192/0x193`，没有回写或清空旧记录。新 ELF 和两块保留区均完成写后校验。释放调试连接后一度无从站，确认 hart 仍为 halted，受保护启动后在 PREOP 重新核对布局；这些均发生在唯一一拍 MIT 之前。

本拍验证的是电机路径，不是 `SingleFd`、同总线多轴容量或耐久验收。没有运行时分支命中记录，不证明两个提前出口在该拍均被执行，也不据此推断最坏耗时或提速。
