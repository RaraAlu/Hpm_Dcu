# EtherCAT 扫描首轮实板测试记录

日期：2026-11-18。结论：**独立扫描镜像经无断点复测后，RK3588 专用口链路 UP，IgH 发现 1 个诊断从站，单模块只读探针识别正确。** 范围只到物理链路、ESC、SII 和只读探针，不验证生产 EtherCAT、SDO/PDO 通信或 CAN。

## 操作与结果

用户确认执行器动力隔离、J-Link 接线正常，并授权先备份保留区再复位、下载、运行诊断镜像。RK3588 普通 SSH 用户已能打开 `/dev/EtherCAT0`。使用 `hpm-ethercat-scan`，未启动生产模块或更改 RK3588 的服务、驱动和网口配置。

| 步骤 | 实际观测 | 判定 |
| --- | --- | --- |
| 备份与烧录 | 不复位先 halt、读回 64 KiB 保留区。收到 `DCU_RETAINED_BACKUP_COMPLETE` 后复位、探测 Flash 并核对备份，再擦除下载、校验镜像与保留区 | 通过，`DCU_DEBUG_READY` 后连接 GDB |
| 初次启动 | 在 `scan_poll` 停点读到 `s_scan_status=0`，IgH 链路 UP 并看到 1 个从站，但首轮 SII 超时，身份为 0，探针读 SM 失败 | 物理链路成立，身份检查未通过 |
| 无断点复测 | 同一镜像未重烧；删除断点后复位并连续运行。IgH 观察到链路重建、SII 扫描完成 | 链路 UP，1 个从站，`PREOP`，标志 `+` |
| 单模块探针 | 只加载 `DriverModule`；读到 Vendor `0x00010000`、Product `0x7fff0001`、Revision `1`；RxPDO/TxPDO 位数与映射数均为 0 | 预期诊断身份及空映射；探针完成后外层限时结束进程 |
| 收尾 | GDB 暂停前读到 `AL_STAT=0x2`、`AL_STAT_CODE=0`、`s_scan_status=0`；前后 64 KiB 逐字节一致 | 目标在诊断镜像上暂停，调试服务和探针均已退出 |

第一次在 PHY 启动后停住，主站仍可见载波，但 MCU 无法继续轮询服务 SII 请求。去掉断点后相同镜像通过，支持该解释；首次失败保留在日志中，不算首次即通过。探针的外层退出码 124 来自限时结束，并非身份读取错误。

通过时主站为 `Idle / Active: no`，从站为 PREOP。未请求 SAFEOP/OP，未写 SDO 或 SII，未发应用 PDO，也未启动 CAN。收尾暂停 MCU 后不再声称当前可做在线 SII 服务，未自动恢复生产镜像。后续采集在线链路时需要目标连续运行。
