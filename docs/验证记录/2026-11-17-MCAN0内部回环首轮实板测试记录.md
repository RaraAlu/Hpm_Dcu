# MCAN0 内部回环首轮实板测试记录

日期：2026-11-17。目标访问时间：20:48:33 至 20:50:08，时区 Asia/Shanghai。

结论：**独立 `hpm-can-loopback` 镜像首轮 MCAN0 内部回环通过。12 帧发送完成、12 帧接收，ID、DLC、类型及载荷全部匹配；没有记录错误或丢弃，控制器已停止。** 这是专用诊断通路的实板证据，不是生产 CAN transport、物理总线或 EtherCAT/CAN 完整往返验收。

## 范围与准备

- 用户本轮重新确认执行器动力及所有业务节点隔离、逻辑供电和 J-Link 接线正常，允许备份保留区后复位、烧录独立镜像并运行一次，结束后暂停、不恢复生产固件。
- 不互连 CAN0/CAN1，不接外部对端，不启动 EtherCAT、motor、SSC、FreeRTOS 或 EEPROM/SII 初始化。测试仍使用专用入口和 ISR/接收队列，没有改写生产配置。
- 上板前重新执行 20 项针对性主机测试、测试镜像构建及 `check-image`，全部通过；工具检查通过，调试端口无占用。本轮未修改固件源码，也没有放宽超时或通过条件。
- 运行参数：MCAN0、内部回环、经典 CAN、`nominal_bitrate_kbps=1000`、ID `0x600`、DLC 8；非对称、全零、全一三种载荷依次重复四次。单帧截止和末尾静默检查各为 5 ms。

## 执行过程

| 阶段 | 实际操作与观测 | 结果 |
| --- | --- | --- |
| 保护与下载 | 使用受保护 `debug-server --preset hpm-can-loopback --skip-build --flash-first` 入口；冻结 ELF、备份保留区、烧录、校验镜像及保留区，然后复位暂停 | 收到 `DCU_DEBUG_READY` 后才连接 GDB |

| 连续运行 | 删除 `main` 断点，只保留 `dcu_can_loopback_finished` 一个硬件断点；不在等待循环暂停，不调用目标函数 | 一次连续运行到结束点，PC `0x80005b6e` |
| 结果取证 | 读取报告、私有队列状态及有限的停止状态寄存器；保存报告二进制和运行后保留区 | 固件 PASS，主机独立逐帧比对通过 |

冻结镜像位于 `artifacts/target/20261117T124833.592520Z/image.elf`，完整 SHA-256 见同目录 `image-check.json` 和 `sha256s.json`。受检擦除范围为 `[0x80000000, 0x80012000)`，与保留区无交集。镜像检查 JSON 的 `hardware_geometry_verified=false` 是离线检查器字段；目标事务另行校验了 Flash bank 容量，未将该字段手工改成 true。

## 实测结果

| 检查项 | 本轮观测 | 判定 |
| --- | --- | --- |
| 最终结果 / SDK 返回 | `DCU_LOOPBACK_PASS` / 0 | 通过 |
| 已核对 / TX 完成 / RX 接收 | 12 / 12 / 12 | 完整，无多收或漏收 |
| IRQ 次数 | 12 | 实际进入专用 MCAN0 ISR；不是仅检查中断使能 |
| 错误 / 队列丢弃 | 0 / 0 | 本轮无记录错误或溢出 |
| 逐帧内容 | 均为 ID `0x600`、DLC 8、标准经典数据帧；8 字节载荷与独立 YAML 基准完全相同，12 项 matched 均为 true | 通过 |
| 软件提交至 ISR 交接 / us | 158、138、136、128、136、136、128、136、136、128、136、136 | 均小于 5000；不据此验收 WCET、抖动或物理线速 |
| 配置后模式 | `mode_cccr=0xa0`、`mode_test=0x10` | TEST/MON/LBCK 成立，INIT/FD/BRS 关闭 |
| 最终硬件停止 | `CCCR=0xa1`、`TEST=0x30310`、`IE=0`、`TXBRP=0`、`RXF0S=0` | INIT 已置位，保留内部回环，无待发送或待接收 |
| 软件队列收尾 | read/write 均为 0，pending_mask 为 0，read_failed 为 false | 队列已排空 |
| 保留区 | 运行前后各 64 KiB，逐字节相同 | 变化字节数为 0 |

`TEST` 含动态只读状态位，因此不要求收尾值与初始 `0x10` 整字相同；本轮收尾的 LBCK 位仍为 1。

二进制报告为 284 字节。通过本轮 ELF 的 GDB `ptype /o` 确认字段布局后，离线解码全部 12 条记录，并与保存的 YAML 基准独立比较，不只依赖固件 PASS 枚举。检查脚本及可读 YAML 结果一并保留。

## 数据保护与收尾

运行前保留区与前四步调试留下的 `retained-eeprom-after-init.bin` 完全一致；本次烧录后事务校验通过，运行后再次读回也逐字节相同。没有重写 SII、格式化保留区或恢复旧备份。

结束前观测到 MCU halted，PC 位于 `dcu_can_loopback_finished`，所有断点均已删除。OpenOCD 与 GDB 退出码均为 0，没有遗留调试服务。GDB 在已主动关闭服务器后退出，日志末尾出现连接被关闭提示，这是关闭顺序导致的提示，不是回环执行中的掉线。

**板上现为独立测试镜像，不是生产镜像，未自动恢复。** 后续复位或重新上电会再次执行这项诊断，不能把当前暂停视为永久硬件隔离；继续保持执行器动力隔离。
