# 隔离核 PDO 回环对照

在同一 RK3588 上用已隔离的 A76 CPU6 跑 60 秒、1 kHz 零使能 PDO，与[同一探针的 CPU4 对照](2026-11-19-大小核PDO回环对照.md)比较。两边保持单核绑定、SCHED_FIFO 80、锁内存、相同原始收发路径和接收分段计时，不启用提前唤醒、后移 DC 更新时间或切换快照。逐拍用 HPM 接受序号核对，尾部继续收取在途回显。CPU4 与 CPU6 属于不同频率策略组，测试前读到两边均为 2.256 GHz；这是当前整机配置下的对照，不单独归因于 `isolcpus`。

CPU6/7 已配置 `isolcpus` 和 `nohz_full`，非绑定工作队列掩码为 `0–5`。预检发现 5 个休眠的 `io_uring` 轮询线程仍允许使用 CPU6/7，因此只在本轮临时限制到 `0–5`，结束后恢复原掩码。采样前后检查普通线程的 CPU/亲和掩码，确认没有无关用户线程可在 CPU6 上运行；设备 IRQ 的实际路由没有指向 CPU6，未修改 IRQ 亲和性。定时器、IPI 和每核内核线程并不因隔离而消失，保留前后计数用于核对。

本轮不接 CAN，不下发 Profile，不改变 PDO 布局或固件。

| 60 秒 / 1 kHz | CPU4（未隔离） | CPU6（已隔离） |
| --- | ---: | ---: |
| 完成间隔绝对偏差 P99.9 | 6.833 µs | 2.459 µs |
| 完成间隔最大绝对偏差 | 10.625 µs | 5.083 µs |
| 超出 ±1 µs | 4847/59999 | 2092/59999 |
| 漏拍 | 0/60000 | 0/60000 |
| 接收调用耗时中位数 | 5.250 µs | 5.250 µs |
| 接收调用相邻耗时变化 P99.9 | 2.625 µs | 1.167 µs |

CPU6 改善了尾部抖动，但仍未达到全程 ±1 µs。CPU6 最坏完成间隔偏差 +5.083 µs 中，唤醒相位贡献 +5.375 µs，接收路径贡献 -0.292 µs。该轮 CPU6 前后快照未见外设 IRQ 增量，仍有 67 次架构定时器 IRQ、61639 次重调度 IPI 和 9 次 IRQ work IPI，不能把整轮计数归因给单拍尖峰。

结束后从站回到 PREOP 主站为 Idle，Profile 只读项前后一致，5 个临时线程掩码已恢复；没有修改生产绑核。原始 CSV、IRQ 快照和日志见 `artifacts/target/pdo-isolated-cpu6-20261119/`。
