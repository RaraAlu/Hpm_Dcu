# 配置驱动生产时序四轴单拍

CAN2 的四台 ENCOS 7216 由 RK 的 `driver_module` 生产周期线程发送一拍全零 MIT。命令序号 1833，N+1 读回的 SM3 回显 1833，发布号 7028439，四轴有效且均为本拍新反馈。未测长时间连续运行。

## 配置来源

当前五轴 Profile 的 [RK 时序配置](../../firmware/app/profile/cfg/rk/五轴台架配置.yaml) 指定 PDO 周期 2000 µs、Sync0 偏移 375 µs、目标到站在 Sync0 前 338 µs、允许偏差 25 µs，生产线程提前 150 µs 唤醒准备发送。实际发帧相位根据从站 DC 时标修正，不用 RK 唤醒时刻冒充到站时刻。

SDO 的周期为 2000 µs，唤醒偏移为 700 µs，相对于 RK 单调时钟网格；供 PREOP 的 Profile 与映射核对逐笔使用，不以 Sync0 为原点，不表示 mailbox 报文已在该微秒到站。生产驱动校验 Profile 身份、拓扑和映射后才采用这套 PDO 调度。启动脚本不提供独立的周期或相位。单拍期间无额外 SDO 或测试线程。

## 实测

下表以命令后的第一个 Sync0 网格点（DC 101389433970501 ns）为零点。到站时标取该次交换的参考钟 FRMW，不是引脚或 MCU 访存时标。

| 帧 | DC 到站时标（ns） | 相对 Sync0（µs） | 结果 |
|---|---:|---:|---|
| N | 101389433633726 | -336.775 | CAN2 ID 1 至 4 全零 MIT |
| N+1 | 101389435632690 | +1662.189 | 回显 1833，新反馈掩码 `0x3c000` |

两帧实际相隔 1998.964 µs，未跨过额外周期。生产窗口统计 `sent=1 matched_n_plus_one=1 missed=0`。四轴 TX 计数分别从 547 增到 548，CAN3 ID 2 仍为 0，boot ID 与拓扑代数不变。HPM 未刷写，CAN TX EOF 后 100 µs 间隔未改，本次没有另测 CAN 总线帧间隔。退出时 HPM 为 PREOP，IgH 主站 Idle、inactive。
