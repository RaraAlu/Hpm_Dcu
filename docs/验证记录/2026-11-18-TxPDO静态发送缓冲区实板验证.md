# TxPDO 静态发送缓冲区验证

发布前只绑定一次 Profile 设备与反馈槽位，以及固定对象字典的镜像地址。每周期遍历通道和轴槽时，同时填 TxPDO 与更新 SDO 镜像；电机诊断页也在同一轮生成。Raw CAN 的帧提取与顺序不变。

生产网关任务直接填 SSC 的静态 `aPdInputData`，删除原应用层全长缓冲区及 `APPL_InputMapping` 的中间复制。SSC 仍按 SyncManager 的地址和长度将完整过程映像写入 ESC；600 µs 准备预算及超时保护不变。没有写死 ESC 地址，没有修改 PDO/SDO 字典或 Profile。

## 离线验证

- 分别采集原版、仅预绑定版和静态直写版的二进制，`cmp` 逐字节一致，共 5328 字节。包括三个 PDO 档位、ENCOS/bjcx 混挂、Raw 旁带和 Raw 全总线反馈。
- 比较映射范围内的每字节与 SDO 镜像，并验证较短档位不会覆盖静态缓冲区的尾部。主机回归 342 项，337 通过、5 跳过；ASan/UBSan 下 52 项 MCU 应用测试通过。Debug/Release 及镜像地址保护检查通过。
- Release 反汇编确认 `APPL_InputMapping` 只剩返回指令。完整映像直接从 `aPdInputData` 写入 ESC。
- Release 的 AXI SRAM 静态用量由 159960 B 降至 159272 B，净减少 688 B，已经计入预绑定表。

离线原始字节：`artifacts/offline/txpdo-static/`。台架日志：`artifacts/target/txpdo-static-20261118130435/`。

## 实板对照

旧版为已修复重连 `TX_LATE`、未改发送缓冲区的 Release，新版包含两步优化。两版均使用同一台架、IgH 探针和 4 ms Sync0，各做 10 轮主站释放与重连，每轮 1000 个普通零使能 PDO。全部成功，从站稳定进入 OP，WKC 为 2、应答达到 1097。每轮读回的 Profile 均为 ID 1、版本 1，未下发或提交配置。

| 最后一轮的最大耗时 | 旧版 | 新版 |
| --- | ---: | ---: |
| 发布起步延迟 | 29 µs | 32 µs |
| 反馈快照、打包和 SDO 镜像 | 64 µs | 42 µs |
| SSC 到 ESC 发布段 | 155 µs | 155 µs |
| 打包到发布完成 | 218 µs | 192 µs |

旧版的 SSC 段包含 RAM 复制，日志未把它单独计时；新版已经移除该复制，但 SSC 段的实测最大值没有下降。上述是各阶段单独取最大值，不可相加重建同一周期。最终周期故障位为 0；SII 回读一致，启动日志保留旧记录并递增到 43。IgH 已退出，HPM 保留新版并暂停。

实板只验证无业务节点的 `MotorWithRaw` 档位；空载耗时不代表混挂实机的最坏耗时。

## 后续布局锁存（离线）

- SSC 发送映像与 RxPDO 槽缓冲继续静态分配。启动绑定 Rx/Tx 地址和已配置设备表；映射变化时才初始化共享发送映像。未配置轴槽和诊断页的固定内容不再每拍填充。回到电机映射时会恢复被 Raw 覆盖的固定区。
- RxPDO 只遍历绑定设备，每路通道头只解一次。对齐的 ESC 写入热路径由 Release 反汇编确认是逐字 `lw/sw`，没有逐字调用 `memcpy`；非对齐与尾字节路径继续保留。
- 5328 字节 TxPDO 与本记录的实板版本逐字节一致；主机回归 343 项，338 通过、5 跳过，新增 Raw 与电机布局切换回归。CAN 收发、PDO/SDO 布局和 600 µs 保护不变。此版本后续上板的结果见[回环周期与布局锁存实板对照](2026-11-18-回环周期与布局锁存实板对照.md)，上方耗时仍是上一版本的数据。
