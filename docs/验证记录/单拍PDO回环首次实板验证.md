# 单拍 PDO 回环首次实板验证

CPU6、SCHED_FIFO 80、锁内存、独立 IgH 探针，以 1 kHz 运行 [单拍回环](单拍PDO回环离线时序.md)。测前已确认 CPU6 无无关用户线程或设备 IRQ 实际指向；临时收紧五个 io_uring 轮询线程的亲和掩码，结束后恢复。未接 CAN，未启用生产 DriverModule。SII/EEPROM 备份和回读一致；仅记录正常追加的启动编号 74、75、76。Profile 前后相同，PDO 仍为 784/1072 字节，截止保护不变。

计划严格核对 32 拍，稳定进 OP 后第一条序号 4813 即失败，探针按要求退出，没有继续把迟到反馈算成成功。IgH 双向域均为 WKC 1，主站收到的旧序号是 4812。每拍轨迹如下（时间相对命令 4813 的主站周期起点）：

| 相对时间 | 事件 |
| ---: | --- |
| +2.920 µs | 主站进入 SM2 写帧发送调用。 |
| 约 +121 µs | 该主站周期内的首个 Sync0；现有流水线此时仍锁存 4812。 |
| 约 +377 µs | 序号 4813 的 RxPDO 槽完整就绪。 |
| +894.251 µs | 主站发出独立 SM3 读请求。 |
| +997.500 µs | 主站收到有效旧反馈 4812；序号校验失败。 |
| 约 +1122 µs | HPM 锁存序号 4813，槽就绪领先本次 Sync0 745 µs。 |
| 约 +1451 µs | HPM 发布 4813；相对它实际锁存的 Sync0 为 +329 µs，未超过 +750 µs 截止。 |

HPM 轨迹由仅诊断镜像启用的 RAM 环形缓冲记录，结束后经 J-Link 回读。主站使用软件发送/处理时间戳；HPM 相对主站相位利用 TxPDO 发布后配对的 ESC DC 低 32 位时钟和 HPM 本地计数近似换算，并非线上物理边沿。相邻样本的相位估计约为 +120–122 µs（模 1 ms），足以确认 RxPDO 槽完成落在首个 Sync0 之后，不能用它拆分线缆、DMA、PDI 中断和内存复制的耗时。

结论：主站的 SM3 回包在 1 ms 内到达，但拿的是上一拍反馈；当前主要瓶颈是 SM2 写到 HPM RxPDO 软件槽完成的时间，尚未细分到线侧或 PDI 路径。最先应拆分 PDI 到达、ESC 读取和槽提交，而不是放宽 TxPDO 截止或接受旧序号。现场最后退出到 PREOP/IgH Idle，HPM 为回读 RAM 诊断而暂停。
