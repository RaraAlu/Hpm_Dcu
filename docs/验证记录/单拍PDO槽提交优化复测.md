# 单拍 PDO 槽提交优化复测

基于 [相位窗口实板验证](单拍PDO相位窗口实板验证.md)。本轮把 RxPDO 槽预留和发布移入 ILM，复用 ESC 读完的时间戳，避免在发布前再次读定时器；以 READY 槽号的原子交换作为唯一交接点。Sync0 只锁存已经交换完成的完整帧，不延后 Sync0、不补捞未就绪帧，也不改超时检查。离线模拟 Sync0 恰在原子交接前后抢占，分别验证不可见和可见；52 项相关测试及 Release、诊断固件构建通过。

同一 CPU6 独立探针二进制，1 kHz、FIFO 80、锁内存。发布提前量 399 µs、Sync0 +255 µs、SM3 +870 µs、构建预算 600 µs，均与前轮相同。

| 指标 | 前轮 | 本轮 |
| --- | ---: | ---: |
| 合格环形轨迹：ESC 读完至提交路径结束（各 127 条） | 9–10 µs，中位数 10 µs | 4 µs，中位数 4 µs |
| 短跑 | 32/32 | 32/32，最晚 +982.241 µs |
| 60 秒目标 | 第 509 拍停止 | 第 553 拍停止，前 552 拍通过 |

本轮失败拍发送 5433，主站调用发送点为 +3.735 µs，在 +981.704 µs 收到旧回显 5432；双向 WKC 都是 1、读回时仍为 OP。HPM 记录 `RX_MISSING`，没有 `TX_LATE`。同一 MCU 时钟下，前一拍 SM2 事件、ESC 读完、提交路径结束分别在 Sync0 前 130、8、4 µs；失败拍则是 Sync0 前 126、4 µs 和 Sync0 后 5 µs。两拍 ESC 读都是 113 µs，失败拍在原子交接前被 Sync0 检查到未就绪。

本轮末段的四组各约 32 条合格轨迹中，SM2 事件至 Sync0 的中位间隔由 135 µs 收窄到 130 µs，而 PDI 入口至槽提交的中位耗时均为 126 µs。主站发送调用没有同量级变化。后续应区分帧实际到达 ESC 与 HPM PDI 中断入口的时间；现有打点不能判定窗口收窄来自线侧还是中断响应。

未接 CAN，未下发 Profile，PDO 布局、生产 DriverModule 和保护不变。SII 回读一致，启动日志正常追加 89、90。探针结束后主站回到 Idle，HPM 退到 PREOP 后暂停。原始数据见 `artifacts/target/pdo-ready-fast-20261119/`。
