# HPM5E31 固件审查规则

只报告 **`hpm-release` 生产可达的问题**。以[生产 CAN 配置](../../firmware/app/profile/cfg/生产CAN配置.yaml)、生产编译参数和 RK `DriverModule` 的实际模式为依据。包括上电、PREOP 维护、OP 周期、异常输入和掉线恢复，以及这些路径依赖的 BSP、汇编、构建清单和生成物。

仅诊断开关启用的分支和仅旧主站使用的兼容模式不列入默认生产路径清单。共用源码按**触发路径**判断，不按文件名一刀切。WG3 设备 PDO 使用 Sync0；只有显式选择调试透传时，才审查对应的 SM2 事件队列、CAN 接收唤醒和未读 SM3 保护。生产开启的计数与故障上报不因名为“诊断”而排除。

| 编号 | 必须保持的行为 | 审查时要追到哪里 |
| --- | --- | --- |
| MCU-01 中断与所有权 | Sync0 快中断只锁存，不调用内核；调用 `FromISR` 的 IRQ 必须处在本机 PLIC 允许阈值内。共享槽先写完整数据，再交出所有权。`volatile` 不保证跨字段一致。 | 从向量追到叶函数，检查抢占、嵌套返回、临界区恢复、IRQ 使能前的资源初始化；检查生产者写与消费者释放是否成对。 |
| MCU-02 实时预算 | ISR、关中断区及周期热路径不得无界等待、擦写 Flash、阻塞打印或分配堆。外设持续产生事件时，也必须给其他总线和 SSC 留出服务机会。 | 按最繁忙的启用拓扑核对 FIFO 深度、每轮处理上限、任务栈与中断栈。时间比较明确单位、同一时基、回绕范围；硬件位计数不得按 CPU 时间解释。 |
| MCU-03 因果反馈 | 严格电机 N+1 必须逐轴关联本拍命令、成功 TX EOF、更晚的同路匹配 RX EOF、反馈解码和截止前 SM3 发布。普通透传不承诺每帧 N+1。 | 分别检查提交、硬件完成、反馈、发布四条路径及失败返回；队列入列、WKC 或旧反馈均不能替代完成证据。见[周期契约](周期锁存与反馈发布契约.md)。 |
| MCU-04 发送授权与失效 | 未就绪、租约过期、总线故障、退 OP、切换拓扑或驱动参数不全时，不得沿旧授权继续发运动命令。恢复不能复用旧使能帧。 | 对照生产状态机，追踪硬件待发项、任务队列、预编码和有效位何时清除；取消未发项不等于已撤回总线帧，更不等于物理停机。 |
| MCU-05 外设与诊断 | 按硬件语义处理 W1C、读清寄存器、FIFO 溢出、总线关闭和 TX 取消。故障不能只表现为没有新数据。 | 核对配置的中断源、标志读取与清除顺序、计数及其上报路径。明确各计数是事件次数、帧数还是估算；区分物理总线号、设备索引和 PDO 槽号。 |
| MCU-06 线格式与生成契约 | 访问前核对 DLC 与有效字节数、ID 类型、字节序、对齐、长度、偏移及掩码。多字节或 packed 数据不得假定自然对齐。 | 对照生产 YAML、生成头、对象存储、ESI/SII 与 RK 双向映射；分别看默认生产拓扑、可选子拓扑和空槽。修改生成物应回到其来源。见[生成清单](生成文件与来源清单.md)。 |
| MCU-07 非易失数据 | 更新 SII 或启动编号不能因读错、半写或掉电丢失每板身份，或重新发出旧编号。无法证明记录为空时，不按出厂空白处理。 | 对照分区和擦除扇区，逐步检查写入、校验、提交、回收及失败重启。检查 OP/SAFEOP 禁写和延期写入错误的可见性。 |
| MCU-08 资源与可构建性 | 寄存器映射、时钟、引脚、RAM 区段和缓存属性按 HPM5E31 生产配置核对。固定缓冲区按最大合法报文、轴数、并发深度计算。 | 查生产交叉编译参数、链接 map、栈水位记录及生成依赖；静态 RAM/ROM 尺寸不证明运行栈有余量，不拿旧构建目录当作本次构建。 |

Architect MCP 的[项目模板](../../.toolkit/templates/hpm5e31/architect.yaml)和[机器可读规则](../../.toolkit/templates/hpm5e31/RULES.yaml)先按文件排除台架 YAML 和专用相位跟踪头；其余文件仍须按生产配置和调用链判断。模板命中不是生产可达证明，也不代替编译和实测。

## 如何记录结论

- **代码问题**：给出规则编号、文件行、可达的状态或时序、实际后果和修正方向。一个现象若可能由多个原因引起，只报告源码能支持的因果链。
- **待台架测量**：写明预设、拓扑、负载和观测点，例如「所有目标轴逐拍 TX 完成增量、反馈序号、SM3 截止余量」。没有测量就不声称满足最坏时延。
- **未覆盖**：列出未纳入编译数据库的文件、工具未解析的条件分支或未匹配的规则。MCP 无规则、工具退出码为零、交叉编译成功，都不是固件验收通过。
- 审查本身不授权接板、烧录、回读、复位或发 CAN。生产单拍与长测的边界按[项目入口](../../AGENTS.md)执行。
