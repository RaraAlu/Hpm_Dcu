# 单路配置网关就绪与确认验证

> 历史说明：该离线预设和专用夹具已退役，本文描述的是退役前的设计，不是当前实机测试入口。

在[单路静态配置网关](单路静态配置网关验证.md)之上新增 `hpm-gateway-session`。只用于离线验证，不修改 BSP、生产固件接口、生产主站或前几份诊断基线。诊断产品码 `0x7fff0005`，布局版本 2，烧录和调试入口拒绝此预设。

回环任务只编入显式会话诊断镜像，负责发送探测并核对回显；它与生产固件共用[就绪状态机](../../firmware/app/gateway/startup/gateway_readiness.c)，不是生产网关的周期入口。

| 状态或事件 | 任务行为与放行条件 |
| --- | --- |
| `PREPARING` | 不等主站。任务用静态 YAML 选中的 MCAN 路由发内部自检，要求每帧实际 TX 完成、RX FIFO 标准帧和挑战字节吻合。不发布业务 TxPDO。 |
| `READY` | 首笔完整自检成功才建立就绪代际。等待主站时按 Profile 间隔持续核验，超时或错误失效。 |
| 一次确认 | 主站读就绪摘要，通过一个 SDO 下载提交 Profile ID、版本、SHA-256、启动标识、就绪代际和请求 ID。不匹配、未就绪或过期都不发放会话；同一请求重发返回原会话，不刷新截止时间。确认成功后仍可停留在 `READY`。 |
| `RUNNING` | 必须当前会话有效、SSC 已进入无 AL 错误的 OP，并出现带正确会话 ID、严格递增序号、长度正确的新 RxPDO；才放行这笔 CAN 业务。不要求再确认。完整匹配的 CAN 回包才生成有效业务 TxPDO。 |
| `HOLD` / `FAULT` | 离开 OP、CAN 错误、就绪失效、确认等待或业务命令超时，撤销会话并清除有效反馈，不再提交新帧。已提交的一帧可完成但其旧样本丢弃。本离线入口不自动恢复。 |

仅 MCU 内部自检探针可以在确认之前使用 CAN。EtherCAT 的链路维护、标准状态转换和只读状态查询不受业务门控；即使先到 OP，未确认也没有业务帧或有效反馈。

## 独立接口

- SDO `0x2102:00`：80 字节只读状态，包含 Profile 摘要和当下有效会话；`0x2103:00`：64 字节激活请求，唯一允许下载的对象；`0x2104:00`：16 字节最近一次请求的结果。沿用[最小网关契约](../../tools/protocol/cfg/最小网关契约.yaml)中这三个管理记录的字节偏移，布局版本按本试验镜像为 2。最近一次结果不代表会话仍有效，见实时状态。
- 业务 PDO 仍由生成的固定条目映射。默认 RxPDO 32 字节，前 8 字节为小端会话 ID，接下来 4 字节为小端非零序号，其余是测试负载。TxPDO 48 字节，前段为完整 RxPDO 的内部 CAN 回显，尾段为样本计数、长度、布局版本和有效标志。**这不是物理回显 Profile 的 PDO ABI。**
- YAML 的 `session` 段提供版本和超时。摘要覆盖规范化后的通道、设备路由、PDO 映射及会话参数；没有逐项配置 SDO，也没有候选配置下载。MCU 只消费构建时生成的描述。

## 跨复位编号

- [网关编号模块](../../firmware/app/boot_identity/gateway_identity.c)先从双扇区日志读出最新有效代号，追加下一代并完整回读后才发放启动标识。高 32 位为持久化启动代号；低 32 位为 0 时是启动标识，非零时是该次启动内的会话序号。发放会话不写 Flash。代号或序号用尽不回绕。
- 每页只写一次 16 字节记录，含版本标记和反码、代号和反码。正常 NOR 擦写中断模型下，不完整记录不能变成另一个有效代号。扇区写满只擦另一个扇区，保留最高有效代号所在的扇区；擦除校验或回读失败不发号。完整落盘但尚未发放的代号也被视为已消耗。
- 本预设的 [NOR 适配](../../firmware/app/boot_identity/port/gateway_id_flash.c)现与生产复用，本预设仍独立构建，候选区域为 `[0x80090000, 0x80092000)`，在生产 SII 保留区之外。它检查容量、扇区和页几何，空白或没有有效记录时拒绝启动，不自行重建初始记录。本轮没有给实际板卡分配或初始化该区域。
- 旧激活在重新 READY 后因启动代号不匹配被拒绝；即使新会话已建立，旧 PDO 也因完整 64 位会话号不匹配被拒绝，不提交 CAN 帧。编号不是鉴权，也不能防止外部恢复旧 Flash 镜像、整片擦除或任意介质损坏导致的回滚。

离线测试使用该固件的编号模块、网关任务、SSC 对象访问和 MCAN 适配；用替身注入 MCAN 寄存器事件、时钟与主站操作。编号验证以同一份文件模拟 NOR，启动两个独立进程模拟复位清空 RAM；第一次记录已接受的激活和 PDO，第二次重放并核对无 CAN 业务发送。另覆盖 36 次启动跨扇区轮换、写入中断、写完即复位、回读失败、擦除中断及空白/编号耗尽。Flash 布局、首装和升级保留见[启动编号日志初始化与烧录保留](启动编号日志初始化与烧录保留.md)。没有测试真实 NOR 掉电、线上报文、实际 CAN、启动耗时或生产运行；实板区域与主站兼容性仍待确认，烧录门禁保持关闭。
