# 生产网关静态 Profile 重连

静态 Profile 仍是通道、路由、型号、限值和 PDO 布局的唯一配置源。Profile 未变化时，掉线、超时和重连不进行配置下发，不发送专用确认帧，也不携带会话号。没有本轮的动态 Profile 下发实现。

| 阶段 | MCU | DriverModule |
| --- | --- | --- |
| 启动 | 从[启动编号日志](启动编号日志初始化与烧录保留.md)取得本次 `boot_id`，不分配会话号。编号为零则进入 FAULT；编号有效才自检 Profile 中的通道和已配置节点，未就绪不收业务。 | 初次打开只读取身份、PDO 档位及活动 Profile 的只读掩码、路由和限值，不写旧配置、Apply 或 Owner。 |
| READY + OP | 自动接管 PDO，等待合法的普通零使能输出建立序号基线；首帧不得请求使能通道或设备。 | 发送普通 Stop/零使能 PDO，并用已有确认序号等待 MCU 接收。 |
| 掉线、退出 OP 或超时 | 停止输出，取消在途 CAN 事务，清空 PDO 暂存和运行态，保留 Profile。 | 检测到链路或 OP 丢失后废弃已准备命令、运动状态和反馈缓存；重连重新走普通 Stop、反馈核对和使能流程。 |
| 恢复 | 将新有效序号作为本次基线，拒绝旧序号。原有电机保护继续生效。 | 只接受反馈恢复之后收到的新上层命令作为重新使能依据，旧操作目标或备用目标不得恢复。 |

PDO/SDO 的索引、长度、偏移、映射、ESI/SII 不变。普通 RxPDO 的板头保留字段重新要求置零；TxPDO `0x6000:0a` 和 SDO `0x2002:04` 读零。`0x2002:01/02/03` 仍可读取启动代次、就绪代次及状态/原因。原有只读路由与增益描述符仅投影活动 Profile，不提供第二个配置源或写入路径。

该保护针对本地暂存、掉线前命令和序号过期。移除每帧会话号后，不能区分被外部重新编号的重放与真正的新命令；主站丢弃旧命令是恢复流程的一部分。严格 WKC 超时、总线/设备故障等仍按既有策略闭锁，不视为允许自动续跑的重连。

[显式会话诊断](单路配置网关就绪与确认验证.md)曾使用独立启动入口（离线预设已退役）：必须提供会话号分配器，READY 后仍须显式激活。它与生产路径共用就绪判定和超时处理，但不能用普通零使能 PDO 代替激活。
