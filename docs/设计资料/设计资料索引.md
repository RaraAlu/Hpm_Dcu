## 维护边界

过期设计原稿、旧工程示例及历史资料已清理，原始材料从 Git 历史追溯，不在当前索引维护失效路径。生成入口、差异及部署边界见[生成文件清单](../当前说明/生成文件与来源清单.md)。

新增设计应写明目标、现有行为、拟改内容和验收条件。设计采纳后更新状态，不把“源码已经出现相应分支”替代测试或硬件验收。
