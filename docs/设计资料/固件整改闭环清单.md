## 验收边界

硬件最坏执行时间、实际栈水位、CAN 并发压力、真实电机启动和物理停机仍需板上验收。离线测试和 CPU 指令仿真不能代替这些项目。本轮不连接、复位或烧录目标板，也不擅自删除产品模式。

评审中的大范围改名、独立 CMake target、第二个真实电机驱动、IMU 驱动、通用跨厂商参数模型属于条件性后续工作，不是被悄悄标成完成的修复项。手册对部分校准模式位的冲突仍需厂商/实物确认。第三方 SSC 既有编译警告未在本轮扩展清理。
