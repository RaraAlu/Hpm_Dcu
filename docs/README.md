## 历史材料

[历史文件与示例清单](archive/README.md)列出旧说明、不可解析材料、重复协议副本和非当前构建入口。第一轮仅增加分类和阅读提示，不移动旧文档、图片、SSC 工具工程或 CAN 日志。

保留旧路径是为了避免破坏相对图片链接、SSC 工具引用和无法解析文件中的未知引用；不意味着这些文件都是当前维护源。`docs/assets/` 和测试子目录的物理迁移留待引用检查与测试入口调整后进行。

## 维护规则

- 当前操作说明优先放在 `current/`；根 README 保留快速开始和硬件操作保护要求。
- 新设计放在 `design/`，注明草案、部分实现、源码已实现或已废弃；硬件验收另记。
- 新验证结果放在 `validation/`，注明日期和源码版本；不覆盖旧现场记录。
- 历史材料分类见 `archive/`；不可解析文件保留原字节，不猜测改写。
- 协议变更先检查生成文件清单，不能只修改 XML、结构体或对象字典中的一处。
